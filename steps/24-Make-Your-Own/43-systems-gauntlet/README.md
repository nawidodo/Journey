# 24-43 · Systems gauntlet — blind re-implementation, the understanding test (stretch capstone)

**Week:** W46+ opt (stretch) · **Track:** P · **Prev:** [`../42-own-key-value-cache`](../42-own-key-value-cache/README.md)

## Objective
The way to know you understood a build is to rebuild it without looking. Pick a Track P step you finished ≥2 months ago (or a random one): re-implement it from memory + spec links only — no peeking at your old `code/`. Then diff your two implementations. This is the recall loop that converts "I followed a plan" into "I own this skill."

## Tasks
- [ ] Draw: pick a step (random or weakest-feeling) — write the design from memory: architecture, key data structures, the tricky invariant (10 min, no code)
- [ ] Build: re-implement from spec links only (the same Resources/Links the step lists), zero reference to your prior `code/`
- [ ] Test: meet the step's Exit Criteria with the *new* implementation
- [ ] Diff: compare old vs new — what you did differently, what you forgot (the forgot-list is the growth), what you improved
- [ ] Debrief: one paragraph per "forgot" → re-read that section of the step, re-explain in `notes/`
- [ ] Rotation: repeat monthly with a new step until the forgot-list is empty
