⚠️ **Lab discipline** (USB/Windows/malware/Android/rootkit tracks): USB attacks, Windows kernel, and malware work in **isolated VMs only**, never on host or networks you don't own. Windows driver builds stay in the Windows VM (test-signing); the macOS DriverKit dext is userspace and host-safe. **Android exploits/malware run in the AVD emulator or your own unlocked device only** — never on a personal/carrier device; public malware samples are for analysis only. **Rootkits/bootkits live in VMs only — UEFI bootkits are strictly QEMU/OVMF** (real-hardware SPI/NVRAM persistence can brick the machine); the macOS rootkit goes on an Intel VM; mobile variants on your own AVD/device. **iOS hooking demos run on a spare device you own** (sideloaded Frida or a jailbroken spare). Windows kernel exploits = BYOVD-style signed-driver bugs — practicing on your own VMs is fine, weaponizing/red-teaming targets requires authorization. Keep all artifacts in the phase's `labs/` folders, and note the target VM config for reproducibility.
